# Desarrollo de Aplicaciones Móviles

## Semana 2: Aplicación de gestión de pizzería

### Descripción del proyecto

Este proyecto consiste en una aplicación desarrollada en Kotlin para gestionar los pedidos de una pizzería. Permite registrar clientes, seleccionar productos, calcular los valores de los pedidos, controlar el inventario y gestionar los estados de entrega.

### Funcionalidades principales

- Registro de clientes y validación de datos.
- Catálogo de pizzas con sus precios e ingredientes.
- Registro y consulta de pedidos.
- Cálculo de subtotal, descuento del 10% para pedidos superiores a 3 pizzas e IVA del 19%.
- Verificación y actualización del inventario.
- Reabastecimiento de ingredientes con validación de cantidades.
- Asignación de repartidores disponibles.
- Cambio de estado de los pedidos: En preparación, Listo y En camino.
- Generación de resumen del pedido para el cliente y la pizzería.
- Manejo de errores y validación de datos.

### Tecnologías utilizadas

- Lenguaje de programación: Kotlin.
- Entorno de desarrollo: IntelliJ IDEA.
- Control de versiones: Git.
- Repositorio remoto: GitHub.

### Estructura del proyecto

- `Main.kt`: menú principal y ejecución de la aplicación.
- `Usuario.kt`: clases Usuario, Cliente y Repartidor.
- `Producto.kt`: definición de los productos.
- `Pedido.kt`: gestión de pedidos, cálculos y estados.
- `Inventario.kt`: control y actualización de ingredientes.
- `Funciones.kt`: funciones auxiliares y validaciones.

### Ejecución

1. Abrir el proyecto en IntelliJ IDEA.
2. Ejecutar el archivo `Main.kt`.
3. Utilizar las opciones del menú principal para registrar pedidos, consultar el inventario y gestionar las entregas.

### Control de versiones

El proyecto utiliza Git para registrar los cambios y GitHub para mantener el repositorio y su historial de versiones.
